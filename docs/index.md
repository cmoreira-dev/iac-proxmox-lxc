# iac-proxmox-lxc

Reusable Terraform (OpenTofu-compatible) module that creates an LXC
container on Proxmox — a VM template, cloud-init/SSH provisioning, and an
optional remote-exec provisioning script.

## Where it fits

This is a **library module**, not live infrastructure by itself. It has
no state and no CI of its own — it's consumed by
[`iac.homelab-live-infra`](https://github.com/cmoreira-dev/iac.homelab-live-infra)
via Terragrunt's `source`, under the `proxmox/**` layer tree (Proxmox is
LAN-only, so those layers only ever run `terragrunt apply` from a laptop,
never in CI — see that repo's docs for why).

The Proxmox provider block itself isn't declared in this module — it's
generated by Terragrunt from `iac.homelab-live-infra`'s
`_providers/proxmox.hcl`, so this module stays reusable across any
Proxmox account/endpoint.

## Inputs (`module/variables.tf`)

Key knobs a consumer sets per LXC:

| Variable | Purpose |
|---|---|
| `lxc_template` | Proxmox LXC template to base the container on |
| `lxc_cpu_cores`, `lxc_memory_mb`, `lxc_swap_mb`, `lxc_disk_size_gb` | Sizing |
| `lxc_storage_pool` | Proxmox storage backend (e.g. `containers-thin`) |
| `lxc_static_ip`, `proxmox_network_bridge`, `proxmox_network_gateway` | Networking |
| `ssh_public_key` / `ssh_private_key` | Access + remote-exec provisioning |
| `lxc_provision_script_path` | Optional post-creation provisioning script |

See `module/variables.tf` for the full list and defaults.
